# ストア説明文（日本語 / English）

ダッシュボードの「ストアの掲載情報」で、言語ごとに貼り付ける。簡潔な説明は 132 文字以内。

## 日本語

### 簡潔な説明
X（Twitter）を常にブロック。必要な分だけ一時解除でき、直近30日の使用時間をグラフで確認できます。

### 詳細な説明
X（Twitter）をつい開いてしまう時間を、減らすための拡張機能です。

twitter.com と x.com を常にブロックし、使いたい時だけ「何分使うか」を決めて解除します。時間が来たら自動でブロックに戻るので、「あと5分だけ」が延々と続きません。

■ 主な機能
・X（Twitter）を常にブロック
・5・10・15・30分のワンクリック解除。1〜120分の指定も可能
・設定した時間が過ぎると自動でブロックに戻る
・ブロック画面に、直近30日の使用時間（合計・1日平均・今日）をグラフで表示
・投稿画面と Grok の利用中はブロックしない
・ブロック時に開く URL（ToDo アプリなど）を設定できる

■ 使い方
1. インストールすると、X（Twitter）がブロックされます
2. 使いたい時は、拡張機能のアイコンをクリックして解除する時間を選びます
3. 時間が過ぎると自動でブロックに戻ります
4. ブロック画面のグラフで、どれだけ使ったかを振り返れます

■ プライバシー
・個人情報の収集や外部への送信は一切行いません
・設定と使用履歴は、お使いのブラウザ内にだけ保存されます
・使用履歴は直近30日分のみ保持します

■ 権限について
・storage: 解除時間・設定・使用履歴の保存
・tabs: 現在のタブの状態確認と、ブロック時の移動先タブの制御
・downloads: 不具合調査用のログを、ユーザーが操作した時だけ保存するため
・x.com / twitter.com へのアクセス: ブロック画面の表示のため

## English

### Short description
Block X (Twitter) by default. Unblock it only for the minutes you choose, and see your last 30 days of usage in a chart.

### Detailed description
Twitter Blocker helps you cut down the time you lose to X (Twitter).

It blocks twitter.com and x.com all the time. When you really need it, you pick how many minutes you want, and it goes back to blocked automatically when the time is up, so "just five more minutes" doesn't turn into an hour.

FEATURES
• Blocks X (Twitter) at all times
• One-click unblock for 5, 10, 15 or 30 minutes, or set any duration from 1 to 120 minutes
• Re-blocks automatically when your time runs out
• Usage chart on the block screen: total, daily average and today, for the last 30 days
• Does not block while you are writing a post or using Grok
• Optional redirect URL that opens while blocked (for example, your to-do app)

HOW TO USE
1. Install the extension. X (Twitter) is blocked right away.
2. When you need it, click the extension icon and choose how long to unblock.
3. When the time is up, the block comes back on its own.
4. Check the chart on the block screen to see how much time you spent.

PRIVACY
• No personal data is collected or sent anywhere.
• Settings and usage history are stored only in your browser.
• Usage history is kept for the last 30 days only.

PERMISSIONS
• storage: saves your unblock time, settings and usage history
• tabs: checks the current tab and controls the redirect tab
• downloads: saves a debug log file, only when you ask for it
• Access to x.com and twitter.com: needed to show the block screen
