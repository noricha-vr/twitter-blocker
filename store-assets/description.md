# ストア説明文

## 簡潔な説明（132文字以内）
X（Twitter）を常にブロック。必要な分だけ一時解除でき、直近30日の使用時間をグラフで管理できます。

## 詳細な説明
X（Twitter）の見すぎを防ぎ、集中できる時間を取り戻すための拡張機能です。

主な機能：
• twitter.com / x.com を常にブロック
• 5・10・15・30分のワンクリック、または1〜120分を指定して一時解除
• 設定時間が過ぎると自動でブロックに戻る
• 直近30日の使用時間（合計・1日平均・今日）をグラフで表示
• 投稿画面と Grok の利用中はブロックしない
• ブロック時に開く URL を設定可能

使い方：
1. インストールすると、X（Twitter）が常にブロックされます
2. 使いたい時は拡張機能アイコンをクリックし、解除する時間を選びます
3. 時間が過ぎると自動でブロックに戻ります
4. ブロック画面のグラフで、直近30日の使用時間を確認できます

プライバシー：
• 個人情報の収集・外部への送信は一切行いません
• 設定と使用履歴はブラウザ内のストレージにのみ保存されます
